# Exemplos de pedidos

Pedidos em português do dia a dia funcionam. Quanto mais você contar sobre o negócio, melhor, mas a
skill pergunta o que faltar antes de desenhar.

## Site novo

```text
cria um site para a minha barbearia em Campinas, com botão para agendar no WhatsApp
quero uma landing page futurista para a minha clínica de estética
faz um site de uma página para uma padaria de bairro, aconchegante e sem exagero de cor
monta um portfólio para uma arquiteta, sóbrio e elegante, com as obras em destaque
preciso de uma página de produto para um fone de ouvido, estilo Apple
```

## Com material pronto

```text
aqui está a logo e as fotos da loja: cria o site usando as cores da logo
gostei do movimento deste site [link], quero algo nessa linha, mas sem copiar
o cliente mandou este print: o planeta está cortando no celular, corrige
```

## Melhorar um site existente

```text
deixa esse site mais bonito e profissional
esse site está travando no celular, deixa leve
as animações estão exageradas, enxuga
revisa as animações desse projeto e me dá um plano de melhoria
testa esse site com nomes enormes, campos vazios e emoji
```

## Publicar

```text
prepara esse projeto para subir na Vercel
confere a segurança do site antes de publicar
atualiza a pasta da Vercel com as últimas mudanças
```

## Dicas

- **Diga o que você não quer.** "Nada de roxo", "sem depoimentos", "não muito colorido" economizam
  uma rodada inteira.
- **Referência é inspiração.** Mande links, mas diga o que gostou neles; a skill nunca copia o tema.
- **Contatos reais.** Enquanto não vierem, o site mostra `[placeholder]` visível, nunca um número inventado.
- **Peça por fase.** "Só a direção de arte primeiro" faz a IA parar na fase 2 para você aprovar.
