# skills/

Pasta usada quando as skills de terceiros são instaladas **dentro** do Orbit:

```bash
node ../ferramentas/baixar-skills.mjs --dentro
```

Nada aqui é versionado no repositório (só este arquivo). Cada skill baixada traz a licença do autor e
um `.orbit.json` com a fonte e o commit exatos. A lista completa está em `../skills.lock.json`.
